# Полная сдача Foodgram

## 1. GitHub — 5 секретов

См. `docs/GITHUB_SECRETS.md`.

Минимум для CI: `YC_REGISTRY_ID`, `YC_SA_JSON_CREDENTIALS`.

Для автодеплоя добавьте: `HOST`, `USER`, `SSH_PRIVATE_KEY`.

## 2. Push кода

```powershell
cd путь\к\foodgram
git add .
git commit -m "Complete foodgram project"
git push
```

## 3. Actions

- **Foodgram CI** — зелёный, образ в registry
- **Foodgram Deploy** — зелёный после добавления SSH-секретов

## 4. Ручной деплой на ВМ (если Deploy не настроен)

```bash
ssh -i ~/.ssh/foodgram_vm yc-user@81.26.183.233
bash -c "$(curl -fsSL https://raw.githubusercontent.com/bilalallazov/foodgram/main/infra/setup_server.sh)"
```

Или:

```bash
git clone https://github.com/bilalallazov/foodgram.git
cd foodgram/infra
cp .env.production.example .env
nano .env
bash deploy.sh
```
