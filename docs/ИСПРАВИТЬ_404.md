# Ошибка 404 nginx/1.24.0 (Ubuntu)

## Причина

На ВМ работает **системный nginx Ubuntu**, а не контейнер Foodgram.

Docker либо не запущен, либо не занял порт 80.

## Исправление на сервере (SSH)

Подключитесь:

```powershell
ssh -i C:\Users\user\.ssh\foodgram_vm yc-user@81.26.183.233
```

Выполните **по порядку**:

```bash
cd ~/foodgram/infra
```

Если папки нет:

```bash
cd ~
git clone https://github.com/bilalallazov/foodgram.git
cd foodgram/infra
cp .env.example .env
```

Запустите скрипт:

```bash
bash fix-404.sh
```

Или вручную:

```bash
sudo systemctl stop nginx
sudo systemctl disable nginx
docker compose down
docker compose up -d --build
docker compose ps
```

## Успех

В браузере http://81.26.183.233 — главная Foodgram, не «404 Ubuntu».

В заголовках nginx должен быть контейнер, не только Ubuntu 1.24.

## Неправильный путь

Не клонируйте репозиторий внутрь `infra/infra/`.

Правильно: `~/foodgram/infra`

## На Windows 404 не исправляется

Docker на ПК не установлен — всё делается **только на ВМ**.
