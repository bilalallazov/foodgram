# Настройка секретов GitHub и Yandex Cloud

Репозиторий: https://github.com/bilalallazov/foodgram

## Какие секреты нужны для CI

| Секрет в GitHub | Откуда взять |
|-----------------|--------------|
| `YC_SA_JSON_CREDENTIALS` | JSON-файл ключа сервисного аккаунта |
| `YC_REGISTRY_ID` | ID реестра Container Registry |

---

## Часть 1. Container Registry (5 минут)

1. Откройте https://console.cloud.yandex.ru
2. Выберите **каталог** (folder), в котором работаете на курсе
3. Меню слева → **Container Registry**
4. **Создать реестр** → имя `foodgram-registry`
5. Откройте реестр → скопируйте **Идентификатор** (пример: `crp1a2b3c4d5e6f7g8h9`)

Это значение для секрета **`YC_REGISTRY_ID`** (только буквы и цифры, без `cr.yandex/`).

---

## Часть 2. Сервисный аккаунт (10 минут)

1. **IAM** → **Сервисные аккаунты** → **Создать сервисный аккаунт**
2. Имя: `foodgram-github`
3. **Добавить роль** (на каталог):
   - `container-registry.images.pusher`
4. Создайте аккаунт
5. Откройте его → **Авторизованные ключи** → **Создать новый ключ** → **Создать авторизованный ключ**
6. Формат: **JSON** → **Создать**
7. Файл скачается (например `authorized_key.json`)

**Содержимое всего файла** — в секрет `YC_SA_JSON_CREDENTIALS`.

Пример начала файла:

```json
{
  "id": "...",
  "service_account_id": "...",
  "private_key": "-----BEGIN PRIVATE KEY-----\n..."
}
```

---

## Часть 3. Добавить секреты в GitHub (3 минуты)

1. https://github.com/bilalallazov/foodgram/settings/secrets/actions
2. **New repository secret**

### Секрет 1

- **Name:** `YC_SA_JSON_CREDENTIALS`
- **Secret:** откройте `authorized_key.json` в блокноте → Ctrl+A → Ctrl+C → вставьте целиком

### Секрет 2

- **Name:** `YC_REGISTRY_ID`
- **Secret:** ID реестра, например `crp1a2b3c4d5e6f7g8h9`

Проверьте: в списке должны быть **ровно эти два** имени (регистр важен).

---

## Часть 4. Перезапуск CI

1. https://github.com/bilalallazov/foodgram/actions
2. Упавший workflow → **Re-run all jobs**

Или в PowerShell:

```powershell
cd "C:\Users\user\Desktop\Новая папка (2)\foodgram"
git commit --allow-empty -m "Retry CI after secrets"
git push
```

Успех: зелёная галочка, в Container Registry появился образ `foodgram_backend`.

---

## Часть 5. Проверка в Yandex Cloud

**Container Registry** → ваш реестр → **Образы** → `foodgram_backend` с тегами `latest` и хеш коммита.

---

## Частые ошибки

| Симптом | Решение |
|---------|---------|
| `denied` при login | Роль `container-registry.images.pusher` на каталог |
| Пустой registry ID | Секрет без пробелов и без `cr.yandex/` |
| Invalid JSON | Вставить весь файл ключа, включая `{` и `}` |
| Секрет не виден workflow | Имена только `YC_SA_JSON_CREDENTIALS` и `YC_REGISTRY_ID` |

## Файл `.env` на сервере (не в GitHub!)

Секреты для **виртуальной машины** задаются в `infra/.env` на ВМ, не в GitHub Actions:

```env
ALLOWED_HOSTS=IP_ВАШЕЙ_ВМ
SECRET_KEY=длинная_случайная_строка
POSTGRES_PASSWORD=надёжный_пароль
ADMIN_PASSWORD=пароль_для_админки
```

В `tests.yml` укажите тот же `ADMIN_EMAIL` / `ADMIN_PASSWORD` и имя ВМ.
